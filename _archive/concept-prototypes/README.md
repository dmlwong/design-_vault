# Archived concept prototypes

Explore-funnel outputs from the Commentary / RAID work — kept for reference, moved out
of the active **vault-health artifacts index** (`tools/artifacts-manifest.json`) so that
index stays focused on the living tools and shareable explainers.

They live here because they **name product surfaces** (RAID / Commentary, initiative
views) and so are deliberately kept out of anything that could reach a public URL. They
remain fully viewable — open any file below in a browser locally.

| File | What it is |
| ---- | ---------- |
| `status-prep-raid.html` | Status Prep — Initiative RAID & Commentary (the concept from the first Ready brief) |
| `delivery-radar.html` | Delivery Radar — cross-initiative RAID (earlier exploration) |
| `initiative-log.html` | Initiative Log — Commentary & RAID (earlier exploration) |
| `commentary-raid-clickable.html` | Commentary / RAID prototype — clickable |
| `commentary-raid-walkthrough.html` | Commentary / RAID prototype — walkthrough |

Live Claude Artifact URLs for these still exist (see git history of
`tools/artifacts-manifest.json` before they were archived) but are intentionally no longer
listed in the vault-health index. `_archive/` is skipped by all vault linters.
