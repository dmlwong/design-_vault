# Archived pipeline explainer

`context-first-prototyping.html` — an HTML "proposal" explainer of the concept-intake
pipeline (the shift, the 11-field form mock, the end-to-end flow, the full 8-criterion
rubric, the two decided forks).

## Why it was retired

It was a near 1:1 render of documents that already exist and stay current:
- `_review/2026-07-21-context-first-intake-proposal.md` (its eyebrow literally read "Proposal · for discussion")
- `design-brain/brief-contract.md` (the 8 criteria, reproduced almost verbatim)
- its form mock is superseded by the **working** form (`tools/intake-form.html` /
  `artifacts/concept-brief-intake.html`)

It had also drifted: it predated `brief-coach`, so it described the pipeline as
rule + reviewer and omitted the coach and the coach/reviewer firewall. Keeping it meant a
third place the pipeline could go stale.

The live flow chart `artifacts/concept-to-prototype-flow.html` (kept, and updated with the
coach stage) carries the current, proof-backed view of the pipeline. `_archive/` is skipped
by all vault linters; this file remains viewable by opening it locally.
