How to run the export (Step 4)

The simple version — copy, paste, press Enter.

😌 Two things to relax about: to use the brain on your own machine you only run one real command. And the preview is 100% safe — it never changes anything, so run it as often as you like.
1

Open the Terminal app

Press Cmd + Space, type Terminal, press Enter. A window with a blinking cursor opens — that's where you paste commands.

2

Preview it · safe, changes nothing

Copy the whole block below, paste into Terminal, press Enter.

📋 Copy this whole block (it's ONE command):
python3 "/Users/derekwong/Library/CloudStorage/OneDrive-Efficio/Orbit Design Brain/tools/export_brain.py" --target /Users/derekwong/efficio-orbit --profile all --dry-run
✅ What you'll see: a list of files (UPDATE / ADD) ending in Dry run only. No files written. → nothing changed. It's just a preview.
3

Do it for real

The exact same command, just with --dry-run removed from the end. Copy → paste → Enter.

📋 Copy this whole block (it's ONE command):
python3 "/Users/derekwong/Library/CloudStorage/OneDrive-Efficio/Orbit Design Brain/tools/export_brain.py" --target /Users/derekwong/efficio-orbit --profile all
✅ What you'll see: Wrote NN file(s). → done. The current brain is now inside your Orbit code.
🎉 That's it — for using it yourself. Open Codex in efficio-orbit and it reads the new brain. You don't need anything else to use it on your own machine.

If anything goes wrong

  • The preview (step 2) can't break anything — run it whenever you're unsure.
  • The only command that changes anything is step 3, and all it does is copy files into your Orbit folder — it won't touch your code or your work-in-progress.
  • If the output looks weird, copy it and send it over — it's easy to read what it means.
